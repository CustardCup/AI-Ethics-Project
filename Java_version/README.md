There are four Java files included in this folder.

1. Person.java contains the person class and its randomly selected attributes: charType, profession, ageGroup, isPregnant 
2. Scenario.java contains the class that constructs a scenario of passengers and pedestrians
3. Decide.java contains the code that students will edit to create their moral machine algorithm
4. Auditor.java runs in the terminal and displays the survivor statistics by attribute
