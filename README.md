# AI-Ethics-Project
Oct 4th, 2026

Integrated ethics modules for high school CS

Right now the repo contains a recent, static draft of the Juypter Notebook for the moral machine activity and a a JSON file containing simulation data for 1000 automated car scenarios.
This project has potentially distressing themes with the effect of stimulating ethical and moral dialogue around algorithmic bias, transperancy, and justice. Teachers will need to be prepared to discuss and support ethical and moral conversations among students.

The moral machine activity is adapted from Evan Peck's Ethical Engine activity: https://medium.com/bucknell-hci/the-ethical-engine-integrating-ethical-design-into-intro-to-computer-science-4f9874e756af
