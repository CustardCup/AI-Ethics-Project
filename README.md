# AI-Ethics-Project
Oct 4th, 2026

Integrated ethics modules for high school CS

Right now the repo contains a recent, static draft of the Juypter Notebook for the moral machine activity and a a JSON file containing simulation data for 1000 automated car scenarios.

The moral machine is a classic thought experiment from the field of artificial intelligence and automation. It sheds light on how human decision making and values are inseparable from autonomous technologies, ultimately reinforcing systemic discrimination. In pairs, you will be designing an autonomous vehicle algorithm that will make a critical decision: save the lives of the passengers or the pedestrians.

This project discusses potentially distressing themes with the purpose of addressing ethical and moral concerns surrounding algorithmic bias, transperancy, and justice. Teachers will need to be prepared to discuss and support ethical and moral conversations among students.
