# AI-Ethics-Project
Integrated ethics modules for high school CS

Right now (Oct 4th, 2026) the repo contains a recent, static draft of the Juypter Notebook for the activity and a a JSON file containing simulation data for 1000 automated car scenarios.
This project has potentially distressing themes and can make participants uncomfortable, but it is exactly for that reason why the activity is so beneficial for stimulating ethical thinking in introductory programming students.
